# Faiz Pitsuwan-Meier – CV site

Static CV site served by GitHub Pages at <https://humanismcontributor.github.io/cv/>.

Tabs: **CV**, **Certificates**, **GitHub Portfolio**, **Contact**, **QR Code** (CV first, so QR scans land on it).

- All content lives in `index.html`; files people can download are in `assets/`.
- The public-repositories list is fetched live from the GitHub API in the browser.
- Personal identifiers (date of birth, place of origin, registration numbers, phone number) are
  redacted from the CV and certificates. Redactions are burned into the page images, not overlaid.
